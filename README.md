# scoop-bucket

Scoop bucket for [Mypack](https://github.com/sinhong2011/mypack).

```sh
scoop bucket add sinhong2011 https://github.com/sinhong2011/scoop-bucket
scoop install mypack
```

The `mypack` package is published here after a stable Mypack release. Pre-releases are only available on GitHub Releases.
